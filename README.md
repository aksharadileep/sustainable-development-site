# 🌍 Sustainable Development Goals Explorer

An interactive and educational web application designed to showcase all 17 United Nations Sustainable Development Goals (SDGs). The platform provides detailed information, engaging visuals, responsive layouts, and interactive elements to help users understand global sustainability challenges and the actions needed to create a better future.

## 📌 Overview

The Sustainable Development Goals (SDGs) were adopted by the United Nations as a universal call to action to end poverty, protect the planet, and ensure peace and prosperity for all by 2030.

This project presents all 17 SDGs through a modern and user-friendly interface, making sustainability education more accessible and engaging for students, educators, and the general public.

---

## ✨ Features

* 🌎 Explore all 17 United Nations SDGs
* 📱 Fully responsive design for desktop, tablet, and mobile devices
* 🎨 Modern UI with interactive animations and transitions
* 📊 Global sustainability insights and statistics
* 📖 Detailed descriptions of each SDG
* ⚡ Fast and lightweight implementation using vanilla JavaScript
* 🎯 Educational and awareness-focused platform

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Responsive Web Design
* CSS Animations

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/aksharadileep/sustainable-development-site.git
```

### Open the Project

Simply open `index.html` in your browser.

No additional installation or dependencies are required.
